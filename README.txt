CAMPUS VOICE — DEMO PROJECT

FILES
- index.html: website structure
- style.css: layout and styling
- script.js: demo interactions and local storage

HOW TO RUN
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js together in the same folder.
3. Double-click index.html to open it in a modern browser.
4. Choose Admin and sign in with demo username: admin and password: Admin@123.

FEATURES
- Student, Staff, HOD, Principal, and Admin demo login roles
- Admin-only New Announcement form to publish announcements
- Admin can edit, delete, and export announcements as JSON
- Left-side dashboard menu: Home, Events, Calendar, Announcements, Important / Pinned
- Latest announcements panel and month calendar with marked event dates
- Like and pin buttons on announcement cards; pinned cards are marked IMPORTANT and appear first
- Search, category filters, audience visibility, and local browser storage

IMPORTANT LIMITATIONS
This is a front-end demo only. Login credentials are hard-coded in JavaScript and are not secure. IDs are not verified by a college server. Announcements, likes, and pins are saved in the current browser only and are not shared with other users or devices. For a real college deployment, use server-side authentication, a backend, and a shared database. The background image uses an online image URL and may require internet access.
